# 向远方 · 2027 欧洲独行手帐
静态、无依赖、适配手机的中文旅行规划站。GitHub Pages 从 main 根目录发布。

打开 index.html 或运行 `python3 -m http.server 8765` 本地预览。

- 日期按各站天数连续重排，默认英国30天＋申根69天＋土耳其10天＋格鲁吉亚7天，共116天。
- 可编辑、新增、删除、排序站点，更新备注和预订状态。
- 预算、签证及行李勾选保存在当前浏览器 localStorage，不自动跨设备同步。
- JSON导出/导入用于手动迁移；清除浏览器数据前备份。
- 公开初始规划不包含证件号码或实际住宿地址。请勿将敏感资料提交仓库。
- 申根提示为保守合计，不替代官方滚动180天计算；各国天数按国家合并。
- 预算口径：语言班3万元＋游玩上限10万元，可调整。
- 页面为规划参考，不代表预订、实时交通或2027年的签证与安全保证。
